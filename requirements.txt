## Code Explanation

### agent_memory.py

- Uses `sqlite3` to create and manage an in-memory SQLite database.
- Contains tables for storing resource information and user session records.
- Provides functions to save and retrieve session data.

### resource_finder.py

- Implements resource discovery functions that query the dummy database.
- Supports filtering resources by type, e.g., hospitals or shelters.

### main_agent.py

- Contains the main handler function `handle_user_request()` that:
- Analyzes user request urgency.
- Calls resource finder to get nearby resources.
- Persists session history.
- Prepares responses as if in a live scenario.
- Structured for easy extension to real API integration.
